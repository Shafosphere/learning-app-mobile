# Android Accessibility Audit — Memicard

Static code audit, Android only. P0 blocks learning; P1 major barrier; P2 significant friction; P3 improvement. `Needs manual verification` = runtime result cannot be proven from code. WCAG references below are 2.2 AA unless marked `AAA` or `Android recommendation`.

## Findings

|---|---|---|---|---|---|
| P1 | `src/components/button/button.tsx` — `MyButton` | All shared button labels set `allowFontScaling={false}`. Fixed-width variants then shrink text with `adjustsFontSizeToFit`. | Low-vision users, users with Android Font size/display size increased. | Allow font scaling; allow labels/buttons to wrap or grow. Test largest Android Font size and display size. | 1.4.4, 1.4.10, 1.4.12 |

| P2 | `src/components/slider/TrackSlider.tsx` | Custom slider handles touch pan only. ## Manual verification — complete study/review flow

| Area | Android check |
|---|---|
| TalkBack | Course select → box select → text/image prompt → answer → correction → true/false → next card → completion → review. Verify meaningful name/role/state, one focus stop per control, spoken error/result/status, and no bridge-input/decorative-image stop. |
| Switch Access / external keyboard | Complete same flow without drag, swipe, long press, or touch-only dismissal. Test focus traversal, Enter/Space activation, slider change, Back/Escape modal dismissal, and return focus. |
| Scaling | Largest Android Font size and Display size: no clipped essential label, hidden action, overlap, or unreachable card/modal content. |
| Contrast / color | Light, dark, high-contrast, deuteranopia, protanopia, tritanopia. Check answer result, correction, box selected/disabled states, charts, and error markers. |
| Modal / motion | Focus enters modal, remains usable, closes with Back, and returns to trigger. With Android Remove animations enabled, verify nonessential movement is reduced and no essential information relies on motion. |

## Confirmed positive coverage

- `MyButton` supplies button role, label, and disabled state.
- `ToggleSwitch` exposes switch role with checked/disabled state.
- `BoxList` supplies labelled button role and selected/disabled state.
- True/false controls use labelled shared buttons; duplicate hidden action layout is excluded from accessibility.
- Popup already declares alert/live-region semantics; Android delivery remains manual verification, not static defect.
